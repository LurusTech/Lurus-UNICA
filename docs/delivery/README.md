### 本轮其它修复（与验收无直接关系，但影响交付）

- ✅ `bbe21be`：四个服务的 Dockerfile 按原样构建会失败（构建上下文缺 `go.work` 列出的模块；构建镜像 Go 1.23 低于 admin 要求的 1.25）。已修正。2026-10-12 已在 WSL 的 Docker 上对候选版本实际执行 `make docker-build`，四个服务镜像（21–26 MB）与告警转发镜像全部构建成功，并空环境启动验证入口（运维手册 2.2）。**这意味着现场正在运行的镜像不是用仓里这几个 Dockerfile 构建的**，现场版本必须先核实。
- ✅ `3944d43`、`bd8d44a`：构建阶段默认走公共 Go 模块代理，国内现场大概率卡在下载依赖。现在可用 `--build-arg GOPROXY=https://goproxy.cn,direct` 指定（默认行为不变）。
- ✅ `f7c8f8f`：WIP 把 judge 加进了 Makefile 的服务清单，`make docker-build` 会去找不存在的 `judge/Dockerfile` 而报错。镜像清单已单列，失败即停。
- ✅ `75f325c`：router 启动日志会打印数据库和 Redis 口令。已改为隐去；现场旧日志里仍有，建议随凭证轮换（收件箱 #6）一并更换口令。

### 本轮没有修、需要决定的

- **`AES_ENCRYPTION_KEY` / `JWT_SECRET` 未设置时会用代码里写死的值**（运维手册 7.2）。改成"未设置即拒绝启动"更安全，但如果现场已经在用默认密钥加密了渠道凭据，升级后会解不开。必须先查现场配置再改。
- **产品界面用了对外禁用词"证据链"**（「判定证据」页的标题和开关，候选版本新增的「实时运营台」页另有两处；「平台管理」页的数据表说明里也有两处，此前就有，操作手册 C-16）。这违反了 `doc/strategy.md` 的话术红线，界面文案要改。手册里没有照抄原文。
