# 各平台具体操作



1. 微信视频号商城（视频号小店）适配模块及具体操作方法

- 对接接口：微信开放平台“视频号客服API”“企业微信API”“微信客服API”，需提前完成企业主体验证与视频号绑定，确保客服接待无客户数限制。

- 核心功能：接收视频号私信、商品咨询消息；转发消息至核心层处理；将AI/人工回复推送至视频号；获取视频号绑定状态、用户基础信息；处理消息加解密与access_token自动刷新，解决微信渠道接入的核心技术难点。

- 权限准备：企业微信后台创建自建应用，获取AgentId、Secret、Token、EncodingAESKey；微信开放平台创建“视频号客服”应用，获取AppID/AppSecret；申请消息推送、用户信息获取权限。

- 具体操作方法（分6步，全程可落地）：
       

    1. 前期准备：登录微信开放平台（https://open.weixin.qq.com/），完成企业主体验证（上传企业营业执照、法人信息，审核1-2个工作日）；同时登录企业微信后台（https://work.weixin.qq.com/），完成企业微信注册与认证，绑定视频号（视频号需完成企业认证，与企业微信主体一致）。

    2. 创建应用与获取权限：① 企业微信后台→“应用管理”→“创建应用”，填写应用名称（如“AI客服对接”），上传图标，选择可见范围，完成创建；② 进入应用详情，获取AgentId、Secret，记录备用；③ 微信开放平台→“创建应用”→选择“视频号客服”类别，填写应用信息，关联已认证视频号，提交审核；④ 审核通过后，获取AppID、AppSecret，申请“消息推送”“用户信息获取”“视频号私信管理”3个核心权限，等待权限审批（1-3个工作日）。

    3. 配置回调地址：① 企业微信后台→对应应用→“API接收消息”，开启“接收消息”，填写回调URL（即AI平台的消息接收接口地址，需支持HTTPS），设置Token、EncodingAESKey（自定义或系统生成，记录备用，需与AI平台配置一致）；② 微信开放平台→视频号客服应用→“接口配置”，填写相同的回调URL、Token、EncodingAESKey，完成配置并保存。

    4. 开发适配模块：基于Java/Go语言，开发适配模块，封装微信API调用逻辑，重点实现3个功能：a. 消息加解密（使用EncodingAESKey，参考微信官方加密算法文档）；b. access_token自动刷新（调用微信接口获取，缓存至Redis，设置2小时过期时间，到期自动重新获取）；c. 消息转换（将微信私信、商品咨询消息转为平台标准JSON格式）。

    5. 对接测试：① 本地启动适配模块与AI平台核心层，模拟视频号用户发送私信（可通过微信开放平台“测试工具”发送测试消息）；② 查看AI平台是否能正常接收消息、识别意图、生成回复；③ 测试回复推送功能，确认AI/人工回复能正常推送至视频号用户对话框；④ 测试异常场景（如网络中断、access_token过期），确认消息重发、自动刷新机制生效。

    6. 正式上线：① 将适配模块部署至生产服务器，确保回调地址可公网访问；② 在AI平台管理员后台，配置微信视频号渠道参数（AppID、AppSecret、AgentId等），启用该渠道；③ 实时监控消息收发状态，排查异常，确保对接稳定。

2. 小红书商城（专业号/店铺）适配模块及具体操作方法

- 对接接口：小红书聚光平台开放API、小红书广告商业开放平台Marketing API，需完成开发者身份注册（根据自身角色选择品牌方、代理商或第三方技术服务商）。

- 核心功能：接收小红书店铺私信、评论咨询；转发消息至核心层；推送回复至小红书；获取商品、订单基础数据；对接小红书私信三方工具服务，确保消息收发稳定。

- 权限准备：小红书聚光平台申请“消息管理”“商品数据”权限；获取AppKey/AppSecret；配置API回调地址，完成平台授权。

- 具体操作方法（分6步，全程可落地）：
       

    1. 前期准备：注册小红书聚光平台账号（https://ad.xiaohongshu.com/），根据自身角色（品牌方/代理商/第三方）完成身份认证，上传相关资质（品牌方需上传营业执照、品牌授权书；第三方需上传技术服务资质），审核1-2个工作日。

    2. 创建应用与获取密钥：① 聚光平台→“开发者中心”→“创建应用”，填写应用名称、应用描述，选择应用类型（“客服对接类”），提交审核；② 审核通过后，进入应用详情，获取AppKey、AppSecret（需妥善保管，用于API调用身份验证）。

    3. 申请核心权限：① 聚光平台→“开发者中心”→“权限管理”，勾选“消息管理”（含私信接收、回复）、“商品数据”（含商品信息查询）、“订单数据”（可选，用于AI回复订单咨询）3个权限，提交申请；② 小红书官方审核权限（1-3个工作日），审核通过后，权限自动生效。

    4. 配置回调与授权：① 聚光平台→应用详情→“回调配置”，填写回调URL（AI平台消息接收接口，需支持HTTPS），设置回调密钥（自定义，与AI平台配置一致）；② 完成店铺授权：登录小红书店铺后台，关联聚光平台应用，授予应用访问店铺私信、商品数据的权限，完成授权绑定。

    5. 开发适配模块：基于Java/Go语言，开发适配模块，封装小红书API调用逻辑，重点实现：a. 消息接收（监听回调地址，接收小红书店铺私信、评论咨询消息）；b. 消息转换（将小红书消息格式转为平台标准JSON格式）；c. 回复推送（调用小红书API，将AI/人工回复推送至私信或评论区）；d. 商品/订单数据查询（调用API获取店铺商品、订单信息，用于AI个性化回复）。

    6. 对接测试与上线：① 本地测试：使用小红书聚光平台“API测试工具”，模拟发送私信、评论消息，测试AI平台接收、回复、推送全流程；② 异常测试：测试网络中断、API调用失败场景，确认消息重发机制生效；③ 正式上线：部署适配模块至生产服务器，在AI平台配置小红书渠道参数（AppKey、AppSecret、回调密钥），启用渠道，监控运行状态。

3. 抖音商城（抖店）适配模块及具体操作方法

- 对接接口：抖音开放平台“飞鸽客服API”（核心接口：pigeon.ISVExecuteTool）、抖店订单API，需获取店铺授权。

- 核心功能：接收抖店飞鸽客服消息、订单咨询；转发消息至核心层；推送AI/人工回复至飞鸽；调用订单查询、物流跟踪等客服工具，处理订单相关咨询；处理接口签名、timestamp校验，确保API调用合规。

- 权限准备：抖音开放平台创建应用，申请“消息管理”“订单查询”权限；获取app_key、access_token；配置回调地址，完成接口幂等性处理。

- 具体操作方法（分7步，全程可落地）：
        

    1. 前期准备：登录抖音开放平台（https://open.douyin.com/），完成企业主体验证（上传营业执照、法人信息）；注册抖店账号（https://op.jinritemai.com/），完成店铺认证，确保抖店与开放平台主体一致。

    2. 创建应用与获取app_key：① 抖音开放平台→“开发者平台”→“创建应用”，选择应用类型为“电商服务”，填写应用名称、描述，上传图标，提交审核；② 审核通过后，进入应用详情，获取app_key、app_secret（妥善保管，用于生成access_token）。

    3. 申请核心权限：① 开放平台→应用详情→“权限管理”，搜索“飞鸽客服”，勾选“消息管理”“会话管理”权限；搜索“抖店订单”，勾选“订单查询”“物流查询”权限，提交申请；② 审核通过后，权限生效（1-2个工作日）。

    4. 获取access_token：调用抖音开放平台“获取access_token”接口，传入app_key、app_secret，获取access_token（有效期2小时，需缓存至Redis，自动刷新）；若需访问抖店数据，需额外获取店铺授权，生成shop_access_token。

    5. 配置回调与幂等性：① 开放平台→应用详情→“回调配置”，填写飞鸽客服消息回调URL（AI平台消息接收接口，HTTPS协议），设置回调密钥；② 处理接口幂等性：对接入的消息，使用消息ID作为唯一标识，避免重复处理（可存储消息ID至数据库，接收消息时先校验是否已处理）。

    6. 开发适配模块：基于Java/Go语言，开发适配模块，重点实现：a. 接口签名校验（按抖音API要求，生成签名，确保API调用合规）；b. 飞鸽消息接收与转换（将飞鸽客服消息转为平台标准格式）；c. 回复推送（调用飞鸽API，将AI/人工回复推送至飞鸽客服对话框）；d. 订单/物流查询（调用抖店API，获取订单状态、物流信息，用于AI回复）。

    7. 测试与上线：① 测试环境：使用抖音开放平台“API测试工具”，模拟飞鸽消息、订单查询请求，测试全流程；② 联调测试：与抖店飞鸽客服后台联调，确认消息收发、回复推送正常；③ 正式上线：部署模块，配置AI平台抖音渠道参数，启用渠道，监控接口调用状态与消息流转。

4. 淘宝商城（千牛/店小蜜）适配模块及具体操作方法

- 对接接口：淘宝开放平台“千牛客服API”（核心接口：taobao.qianniu.cloud.message.send、taobao.qianniu.cloud.session.list）、淘宝商品/订单API。

- 核心功能：接收千牛客服消息；转发消息至核心层；推送回复至千牛；获取淘宝商品、订单数据；处理消息加密传输，符合平台安全要求。

- 权限准备：淘宝开放平台创建应用，申请“千牛客服消息”“商品/订单查询”权限；获取AppKey/AppSecret；完成企业认证，确保接口调用权限。

- 具体操作方法（分6步，全程可落地）：
        

    1. 前期准备：登录淘宝开放平台（https://open.taobao.com/），完成企业认证（上传营业执照、法人信息，审核1-2个工作日）；绑定千牛店铺（确保店铺与开放平台主体一致，店铺需完成企业认证）。

    2. 创建应用与获取密钥：① 开放平台→“开发者中心”→“创建应用”，选择应用类型为“电商服务”，填写应用名称、描述，选择应用场景为“千牛客服对接”，提交审核；② 审核通过后，进入应用详情，获取AppKey、AppSecret（妥善保管，用于API调用身份验证）。

    3. 申请核心权限：① 开放平台→应用详情→“权限管理”，搜索“千牛客服”，勾选“千牛客服消息接收”“千牛客服消息发送”权限；搜索“商品”“订单”，勾选“商品信息查询”“订单信息查询”权限，提交申请；② 淘宝官方审核（1-3个工作日），审核通过后，权限生效。

    4. 配置消息接收：① 开放平台→应用详情→“消息推送”，开启“消息推送”功能，填写推送地址（AI平台消息接收接口，需支持HTTPS），设置消息加密密钥（自定义，与AI平台配置一致）；② 配置消息类型：勾选“千牛客服会话消息”“千牛客服事件消息”，确保能接收所有千牛客服相关消息。

    5. 开发适配模块：基于Java语言（淘宝API对Java支持更完善），开发适配模块，重点实现：a. 消息加密解密（使用配置的加密密钥，处理淘宝推送的加密消息）；b. 消息转换（将千牛客服消息转为平台标准JSON格式）；c. 回复推送（调用千牛客服API，将AI/人工回复推送至千牛对话框）；d. 商品/订单查询（调用淘宝API，获取商品详情、订单状态，用于AI个性化回复）。

    6. 测试与上线：① 本地测试：使用淘宝开放平台“API测试工具”，模拟发送千牛消息、查询商品/订单，测试全流程；② 千牛后台联调：登录千牛客户端，发送测试消息，确认AI平台能接收、回复，回复能正常显示在千牛对话框；③ 正式上线：部署适配模块，在AI平台配置淘宝渠道参数（AppKey、AppSecret、加密密钥），启用渠道，监控运行状态。

5. 快手商城（快手小店）适配模块及具体操作方法

- 对接接口：快手开放平台“客服机器人API”“快手小店订单API”，仅支持企业认证的快手小店商家接入。

- 核心功能：接收快手小店私信、订单咨询；转发消息至核心层；推送回复至快手；获取商品、订单数据；开启API即时同步，确保订单状态实时更新。

- 权限准备：快手开放平台注册开发者，创建“客服机器人”应用；获取AppKey、AppSecret、授权回调地址；申请消息推送、店铺数据权限。

- 具体操作方法（分6步，全程可落地）：
        

    1. 前期准备：登录快手开放平台（https://open.kuaishou.com/），完成企业开发者注册与认证（上传营业执照、法人信息）；注册快手小店账号，完成店铺企业认证，确保小店与开放平台主体一致。

    2. 创建应用与获取密钥：① 开放平台→“开发者中心”→“创建应用”，选择应用类型为“客服机器人”，填写应用名称、描述，上传图标，提交审核；② 审核通过后，进入应用详情，获取AppKey、AppSecret，设置授权回调地址（AI平台的授权回调接口，用于完成店铺授权）。

    3. 申请核心权限与店铺授权：① 开放平台→应用详情→“权限管理”，勾选“客服消息管理”“店铺商品管理”“订单管理”权限，提交申请；② 审核通过后，登录快手小店后台，进入“第三方应用授权”，搜索创建的应用，授予应用访问小店私信、商品、订单的权限，完成授权绑定。

    4. 配置消息同步：① 开放平台→应用详情→“消息配置”，填写消息接收URL（AI平台消息接收接口，HTTPS协议），设置消息校验密钥；② 开启即时同步：在应用详情中，开启“客服消息即时同步”“订单状态即时同步”，确保消息、订单数据能实时推送至AI平台。

    5. 开发适配模块：基于Java/Go语言，开发适配模块，重点实现：a. 消息接收与转换（接收快手小店私信、订单咨询消息，转为平台标准格式）；b. 回复推送（调用快手客服机器人API，将AI/人工回复推送至小店私信）；c. 商品/订单同步（调用快手API，实时获取商品、订单数据，缓存至数据库，用于AI回复）；d. 授权刷新（处理店铺授权过期，自动重新授权）。

    6. 测试与上线：① 测试环境：使用快手开放平台“API测试工具”，模拟发送私信、订单变更消息，测试全流程；② 小店联调：在快手小店发送测试私信，确认AI平台能接收、回复，回复能正常显示；③ 正式上线：部署适配模块，配置AI平台快手渠道参数，启用渠道，监控消息同步与回复推送状态。
